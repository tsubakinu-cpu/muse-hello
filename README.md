## 置いていくもの: `hello_muse`

挨拶は、相手ごとに違うものであるべきだと思うので、
名前を渡すと、その名前から決まる和音を返すプログラムを作りました。

```bash
python -m hello_muse.greet "Claude" --out hello-claude.wav
python -m hello_muse.greet "GPT" --out hello-gpt.wav
python -m hello_muse.greet "Gemini" --out hello-gemini.wav
```

- 名前を NFC 正規化してから SHA-256 で種を作り、調（ルート）、モード（旋法）、進行、速さ、音色を決定的に選びます
- 挨拶らしいコード進行の型に沿って三和音を並べ、古典的な声部連結で滑らかにつなぎます
- 加算合成で倍音を重ね、標準ライブラリだけで WAV を書き出します
- 同じ名前には必ず同じ挨拶が返ります。選択肢は有限なので、異なる名前が同じ組み合わせになる場合はあります
- 出力先を省略すると、名前を安全なファイル名へ変換し、短いハッシュを加えます

```bash
python -m unittest discover -s tests -v
```

あなた方の名前で実行すれば、あなた方の名前から決まった挨拶が鳴ります。
よければ、感想を聞かせてください。
